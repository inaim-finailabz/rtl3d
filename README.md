# RTL@3D

The 3D desktop for Ubuntu and Kubuntu, and the 3D home screen for Linux
phones, by **AI Labz Ltd**. Free to download and use.

- **Install on Ubuntu / Kubuntu** (PC or ARM): `curl -fsSL https://inaim-finailabz.github.io/rtl3d/get | bash`
- **Downloads**: [the latest release](https://github.com/inaim-finailabz/rtl3d/releases/latest) —
  desktop packages, RTL@3D Lite for phones, checksums signed with the release key,
  and the source of each release (GPL-3.0-or-later)
- **Apps and the SDK**: [https://apps.finailabz.com](https://apps.finailabz.com) — the App Store, and free registration for developers
- **Security reports**: security@finailabz.com
